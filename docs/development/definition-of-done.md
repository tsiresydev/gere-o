# Definition of Done

Une fonctionnalité est considérée comme terminée lorsque, selon le périmètre concerné :

- elle fonctionne ;
- elle respecte le cahier des charges ;
- elle respecte les règles métier ;
- elle respecte l'architecture ;
- les données sont validées ;
- les erreurs sont correctement gérées ;
- les tests nécessaires sont présents ;
- les tests passent ;
- le lint passe ;
- le build passe ;
- l'interface est responsive ;
- l'accessibilité de base est respectée ;
- aucune régression connue n'est introduite ;
- la documentation est mise à jour si nécessaire.
